# YouTube URL — загрузчик видео

Это мой учебный проект на Python. Я сделал сайт, на котором можно зарегистрироваться, вставить ссылку на YouTube, выбрать доступное качество и скачать видео. У каждого пользователя есть своя история загрузок.

## Что умеет проект

- регистрация и вход в аккаунт;
- получение названия, автора, обложки и доступных разрешений видео;
- скачивание выбранного качества через `yt-dlp`;
- отображение прогресса загрузки;
- просмотр истории и повторная загрузка из неё;
- удаление записей из истории.

## Технологии

- **Python и FastAPI** — серверная часть и страницы сайта;
- **Jinja2, HTML и CSS** — интерфейс;
- **JavaScript** — обновление прогресса загрузки;
- **SQLite** — пользователи и история;
- **Redis** — состояние фоновых задач загрузки;
- **yt-dlp** — получение информации и скачивание видео;
- **FFmpeg** — объединение видео и аудио в один файл.

## Что нужно установить

Нужны Python 3.10 или новее, Redis и FFmpeg. Также понадобится доступ к интернету.

## Как запустить локально

Открой терминал в папке проекта и выполни команды:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запусти Redis в отдельном окне терминала. Если Redis установлен локально:

```bash
redis-server
```

Затем в первом окне запусти сайт:

```bash
uvicorn app.main:app --reload
```

Открой в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000). При первом открытии сайт предложит войти или создать аккаунт.

Если Redis работает не на этом компьютере, можно указать его адрес через переменную `REDIS_URL`. Путь к базе SQLite можно изменить переменной `DATABASE_PATH`.

## Как устроены файлы

```text
app/
├── main.py                 # маршруты сайта, аккаунты, история и задачи
├── services/
│   └── youtube.py          # получение форматов и скачивание через yt-dlp
├── static/
│   ├── css/                # стили страниц
│   └── js/app.js           # обновление прогресса
└── templates/              # HTML-страницы
```

Скачанные файлы сохраняются в `downloads/`, а история и аккаунты — в `media_downloader.db`. Эти локальные данные и секрет сессии не отправляются в Git: они добавлены в `.gitignore`.

## Как отправить изменения в GitHub

README уже добавлен в проект. Чтобы отправить текущие изменения в настроенный репозиторий `origin` из ветки `main`, выполни:

```bash
git add README.md .gitignore app requirements.txt
git commit -m "Update downloader and add project README"
git push origin main
```

Перед отправкой можно посмотреть, какие файлы попадут в коммит:

```bash
git status
```
